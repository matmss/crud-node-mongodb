# Task Manager

A simple task management web app built with Node.js, Express, and MongoDB (Mongoose), rendered with EJS.

## Features

- List tasks (newest first)
- Add a new task (title + optional description)
- Toggle a task's completed status
- Delete a task

## Getting Started

1. Install dependencies:
   ```bash
   npm install
   ```
2. Copy `.env.example` to `.env` and set your MongoDB connection string.
3. Start the app:
   ```bash
   npm start
   ```

See [MODERNIZATION.md](MODERNIZATION.md) for details on the app's structure and recent updates.
